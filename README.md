# Simple语言词法分析器

基于 DFA（确定有限自动机）实现的 Simple 语言词法分析器。

---

## 文件说明

| 文件 | 说明 |
|------|------|
| `lexer.py` | 词法分析器主程序（DFA 实现） |
| `test.simple` | Simple 语言示例源文件 |
| `test_lexer.py` | 自动化测试套件（60 个测试用例） |

---

## Simple 语言定义

### 关键字（13个）
`if` `else` `while` `for` `do` `int` `float` `return` `void` `break` `continue` `true` `false`

### 运算符（21个）
| 符号 | 名称 |
|------|------|
| `+` `-` `*` `/` `%` | 算术运算符 |
| `=` | 赋值运算符 |
| `==` `!=` `<` `<=` `>` `>=` | 关系运算符 |
| `&&` `\|\|` `!` | 逻辑运算符 |
| `++` `--` | 自增/自减运算符 |
| `+=` `-=` `*=` `/=` | 复合赋值运算符 |

### 分隔符（8个）
`(` `)` `{` `}` `[` `]` `;` `,`

### 标识符
字母或下划线开头，后跟任意字母、数字或下划线。

### 无符号数
- **整数**：纯数字，如 `0`、`42`
- **浮点数**：含小数部分和/或指数部分，如：
  - `3.14`（小数）
  - `.5`（小数点开头）
  - `3e5` / `3.14e+2` / `.5e-10`（指数）

## DFA 状态设计

```
状态编号  状态名          说明
   0     START           初始状态
   1     IN_ID           读取标识符/关键字中
   2     IN_INT          读取整数部分
   3     IN_DOT          读到小数点，等待小数数字
   4     IN_FRAC         读取小数数字
   5     IN_E            读到指数符号 e/E
   6     IN_EXP_SIGN     读到指数后的 +/-
   7     IN_EXP          读取指数数字（接受：浮点数）
  10     IN_PLUS         读到 +（区分 ++ / += / +）
  11     IN_MINUS        读到 -（区分 -- / -= / -）
  12     IN_STAR         读到 *（区分 *= / *）
  13     IN_SLASH        读到 /（区分 // /* /= /）
  14     IN_ASSIGN       读到 =（区分 == / =）
  15     IN_LT           读到 <（区分 <= / <）
  16     IN_GT           读到 >（区分 >= / >）
  17     IN_NOT          读到 !（区分 != / !）
  18     IN_AMP          读到 &（等待第二个 & 构成 &&）
  19     IN_PIPE         读到 |（等待第二个 | 构成 ||）
  20     IN_LINE_CMT     行注释（// ...）中
  21     IN_BLK_CMT      块注释（/* ... */）中
  22     IN_BLK_STAR     块注释中读到 *，等待 /
```

### 关键设计原则
1. **最长匹配**：多字符运算符优先（如 `++` 优先于 `+`）。
2. **关键字识别**：先读取完整标识符，再查关键字表区分。
3. **无符号数**：DFA 通过状态跳转依次处理整数→小数→指数各部分。
4. **注释处理**：`//` 和 `/* */` 作为 DFA 状态内联处理，不产生 token。

## 使用方法

### 运行词法分析器
```bash
python3 lexer.py <源文件路径>
# 示例
python3 lexer.py test.simple
```

### 运行测试套件
```bash
python3 test_lexer.py
```

## 输出格式

每行输出一个 token，格式为：
```
(类型名称，词素值)
```

**示例**（输入 `for(int i=0;i<5;i++) {sum +=i;}`）：
```
(FOR关键字，for)
(左括号，()
(INT关键字，int)
(标识符，i)
(赋值运算符，=)
(整数，0)
(分号分隔符，;)
(标识符，i)
(小于运算符，<)
(整数，5)
(分号分隔符，;)
(标识符，i)
(自增1运算符，++)
(右括号，))
(左花括号，{)
(标识符，sum)
(加赋值运算符，+=)
(标识符，i)
(分号分隔符，;)
(右花括号，})
```

## 异常处理

遇到词法错误时，先输出已识别的所有 token，再输出错误位置（行号 + 列号）：
```
(已识别的token...)

[词法错误] 行X, 列Y: 非法字符: '?'
```
